## Practical guides

`guides/` holds plain, sourced guides on AI memory and identity. The content lives in `scripts/build_guides.py`. To re-check a guide each month: update the facts and the `CHECKED` date in that file, run `python3 scripts/build_guides.py`, and commit. Every fact carries a label (From the source, Reported, Our reading, Speculation) and a numbered source.
