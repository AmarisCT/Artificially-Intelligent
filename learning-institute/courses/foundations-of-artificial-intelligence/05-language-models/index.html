Language models

Systems like chatbots are built on language models. This lesson explains in plain terms what these models do, how they are trained, and where their fluency can mislead.

Learning objectives

  • Explain next-word prediction.
  • Describe the role of scale and of training on human feedback.
  • Explain why fluent output is not the same as accuracy.

Predicting what comes next

A language model assigns probabilities to what text is likely to come next. Text is split into pieces called tokens, and the model predicts the next token given the ones before it. Repeating the step produces text. The demonstration below uses a very small version trained on a short passage so that you can see the principle directly.

Modern models use the transformer architecture, which lets every position in a text weigh other positions through a mechanism called attention [1]. They are trained on vast amounts of text. Researchers reported in 2020 that scaling up such a model made it able to perform many tasks from a few examples placed in the prompt [2].

From prediction to assistant

A model trained only to predict text is not by that fact a helpful assistant. Later stages of training use human feedback to shape the model towards answers people judge to be better, as described in a 2022 paper on following instructions with human feedback [3]. This changes behaviour but does not make the model a different kind of thing. Different AI systems are built differently: image classifiers, game-playing agents and language models are not architecturally the same.

Fluent is not the same as true

Because the training goal is plausible text, a language model can produce confident statements that are false. Critics have argued that models trained on form alone do not have access to meaning, and warned about the risks of treating fluent output as understanding [4, 5]. Others argue that the question of understanding is open and that behaviour on tasks is relevant evidence. This debate returns in the next two lessons.

A worked example: why a fluent answer can be wrong

Suppose you ask a language model for a reference on a narrow topic. The model has learned that references tend to have authors, a title, a journal and a year, and it can produce text with that form. If it does not have a reliable record of a real source, the most probable-looking text can still be a source that does not exist. The sentence reads like a citation because the model has learned what citations look like. Whether the reference is real is a separate matter that the form does not settle. This is why you should check sources independently, especially for claims that matter.

Common misunderstandings

  • “A language model looks up facts in a database.” By default it generates text from patterns learned in training. Some systems add search or retrieval, which changes how they work.
  • “All AI systems work like chatbots.” Image classifiers, game-playing systems and language models are built differently and have different strengths and failure modes.

Reflection question

A language model writes a confident paragraph that contains an invented citation. Explain, using this lesson, how that can happen.
